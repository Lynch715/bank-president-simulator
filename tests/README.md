# 回归测试

游戏本体 `index.html` 是单文件、零依赖的。这个目录只服务于测试,**不影响发布**——发布只需要 `index.html` 和那几张图片。

## 怎么跑

```bash
cd tests
bash run-all.sh          # 全套(校准默认 400 局)
bash run-all.sh 800      # 校准跑 800 局,数字更稳,也更慢
npm run quick            # 只跑不需要依赖的四组,几秒钟出结果
```

首次运行会自动 `npm install` 两个测试依赖(`jsdom` 做 UI 测试、`@napi-rs/canvas` 做传记出图)。**装不上也没关系**,需要它们的三组会自动跳过,其余照跑。

## 原理

`lib.js` 把 `index.html` 里的 `<script>` 块抠出来,当普通脚本在 Node 里 `eval`。游戏本身写了无头分支(`typeof document === "undefined"` 时 `showModal` 自动随机选一个可用选项),所以不需要浏览器也能跑完整局。

`lib.js` 还带一个 `shim()`,给 P0 之前的老版本补上无头守卫——这样新旧两版能用**同一套策略**跑,难度带的对比才有意义。

## 各组测什么

| 文件 | 测什么 | 要依赖吗 |
|------|--------|---------|
| `01-headless.js` | 无头跑 200 局,硬门槛是零报错;顺带看中位存款、结局分布、四条路线覆盖 | 否 |
| `02-meta.js` | P0:v5 老档迁移后能玩到结局、图鉴/成就/阅历落盘、10 个天赋各自不产生 NaN、传记绘制流程 | 否 |
| `03-p1.js` | P1:周期三段与抖动、提前两月吹风且只吹一次、dirt=0 永不爆、dirt=6 爆雷率、顾清越挡一次且只挡一次、三套黑天鹅各走通三幕且分支有差异、站队三选项与专属事件过滤、净息差成本按月归零 | 否 |
| `04-p2.js` | P2:同种子逐字节复现、三个挑战模式初始状态、廉政风暴禁用灰色选项(含全灰不禁的保护)、巡视月份三种排布、速通 24 月出结局、四套对手剧本、同业群消息池 | 否 |
| `05-ui.js` | 用 jsdom 真点按钮:首屏 → 取名 → 选路线 → 跑满任期 → 结局页 → 图鉴四页 → 传记 → 二周目天赋 → 挑战模式开局。全程要求零 console 报错 | jsdom |
| `06-balance.js` | 数值校准:同一套外部策略跑当前版和 `index.P0前备份.html`,比完赛局中位存款(要求 ≤±10%),并按周期统计不良发生率(收紧期要比宽松期高 ≥40%) | 否 |
| `07-clicks.js` | 点击数:jsdom 里跑满 36 个月,数玩家一共点了几下。要求月均不高于原版 3.44、季末月均低于原版 5.4 | jsdom |
| `08-bio.js` | 传记长图:用真 canvas 出一张 PNG 到 `tests/out/传记.png`,自己开来核对版式 | @napi-rs/canvas |

## 几个坑,先说在前面

- **无头模式在每个事件里随机选项**,等于大约一半的时候都在选灰色选项。所以 `01` 和 `06` 里的**完赛率偏低是正常的**(把柄攒得比真人快得多),不要当成难度指标。**中位存款和不良率对比才是有效读数。**
- `06-balance.js` 依赖 `../index.P0前备份.html` 当基线。基线文件没了就只报当前版数字,不做对比。
- `08-bio.js` 出的图,中文能不能显示取决于系统有没有中文字体;没有的话会是一排方框,**但版式(位置、换行、有没有溢出)照样能看**。
- `run-all.sh` 最后会检查 `模拟银行.html` 和 `index.html` 是否一致。改完记得 `cp index.html 模拟银行.html`。
