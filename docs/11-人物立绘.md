# 人物立绘

使用内置 image_gen 工具生成透明背景的现代职场写实人物，配合原有藏蓝与暖纸白页面。统一提示词和逐人物描述保存在 assets/portraits/prompts.json。

## 资源与覆盖

23张资源：6位主要关系人，8位同行行长，玩家行长，老张、小刘，以及6种随机员工职业形象。陆嘉禾沿用青年员工形象；招聘姓名固定对应员工形象，多位员工可能使用同一张职业形象。培训、特质变化、换岗和读档均不改变匹配，不向存档新增字段，也不调用经营随机数。

原图位于 assets/portraits/source/，透明 WebP 运行图位于 assets/portraits/web/，清单为 assets/portraits/manifest.json，总览为 assets/portraits/overview.jpg。build.py 生成运行图并把图像数据内嵌进 index.html 和模拟银行.html，两个入口保持一致，独立复制 HTML 也能显示人物。

## 页面接入

- 关系与团队：人物卡片显示完整半身像，点击立绘可看大图并返回账册。
- 招聘：每份简历包含固定人物预览，入职后沿用同一形象。
- 排行：八位同行与玩家有可点击的人物缩略图。
- 弹窗：人物主线、拜访及其他提及人物的事件按标题优先匹配人物，最多显示两人；取名、月报、图鉴、天赋等非人物界面主动清理旧立绘。
- 手机：人物与姓名置顶，说明和操作占满卡片宽度。大图使用 contain，保留完整人物；弹窗仍可滚动。
