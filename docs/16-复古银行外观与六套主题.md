# 复古银行界面与六套外观

## 设计

根据参考图中的复古经营游戏语言，采用暗色场景、暖金金属框、奶油色内容面板、衬线标题和立体按钮。复用原有银行场景与人物立绘，不增加图片下载依赖；金属线条与细纹由 CSS 绘制，没有持续动画或大面积模糊。

| 外观 | 色彩方向 | ID |
| --- | --- | --- |
| 翡翠鎏金（默认） | 墨绿、暖金、奶油纸 | emerald |
| 深海藏蓝 | 藏蓝、香槟金、浅灰蓝 | sapphire |
| 绯红典藏 | 酒红、古铜、暖米色 | burgundy |
| 紫檀夜宴 | 紫檀、浅金、浅灰紫 | plum |
| 曜石黑金 | 曜石、鎏金、象牙白 | obsidian |
| 经典纸墨 | 保留原有米白藏蓝风格 | paper |

开屏增加银行场景与经营纪事标识；经营界面增加行长档案、场景页眉、金属框架和图标章。人物大图仍可点击，原有底部导航、安全区、图鉴层级、单层滚动及重开重选任期规则保留。

## 换肤与保存

- 开屏“界面外观”和游戏“设置”均能进入选择器。六套外观放在设置顶部，点击立即生效，保留当前设置页和滚动位置。
- 使用独立的 `jbzh_theme` 偏好；不写入任期存档、图鉴或阅历数据，也不消耗随机数、现金、精力。重开和刷新后保留选择。
- 在文档头部先恢复主题，减少首次绘制的颜色跳变，同时更新浏览器主题色。
- 遇到存储被禁止、写入失败或失效的主题 ID，仍可正常游戏和换肤；失效 ID 回退翡翠鎏金，写入失败显示本次无法记住外观。
- 两个 HTML 入口均内嵌完整样式，可继续单文件离线运行。

样式源：`styles/grand-banking.css`；同步命令：`python3 scripts/sync-styles.py`。同步器同时核对原有纸墨样式和新增外观样式。
