# 安卓启动空白修复

本文记录第一轮修复。用户后续截图已证明仍有启动失败；15秒超时永久阻断的后续修复与新验收见《13-慢加载启动恢复.md》。

## 证据与边界

用户截图表现为静态页面样式正常，指标、行动、账册为空，工具栏仍有`[icon:book]`占位文字。该组合符合主脚本未完成初始化的表现。截图没有浏览器错误日志，因此不能确定 iQOO 15 原机触发了哪一个异常，也不能把它归因于手机硬件或机龄。

修复前的两项本地复现：

- ES2019 解析在决策回执的可选链处报 Unexpected token，导致整段主脚本无法执行。
- 禁用 Text.replaceWith 后，图标转换报 TypeError，后面的启动代码没有执行；引导未显示、指标为空、图标占位文字残留，与截图表现一致。

以上是可复现的失效路径，不代表已经取得原手机的错误日志。

## 修改

- 主脚本移除可选链和 Unicode 属性正则；静态工具栏直接使用 SVG。动态图标改用基础 DOM 接口，失败时降级为可读文字，不阻断经营逻辑。
- 独立 ES5 启动保护先于主脚本执行。主脚本解析失败、运行时中断或长时间未完成时，显示错误、版本和浏览器详情，可复制诊断并导出原始进度。JavaScript 被禁用时显示启用说明。
- matchMedia、MutationObserver、requestAnimationFrame、focus 选项和 Canvas 等可选能力提供降级。没有 MutationObserver 仍同步转换图标并维持弹窗的背景隔离。
- 存储权限被拒绝、存储额度不足时可以开始经营，并提示不能自动保存；不再因 localStorage getter 抛错而中断启动。
- 损坏或无法读取的进度不再悄悄转入新局。保留原始存档、停止写入，提供备份入口；旧版有效存档补齐缺失的界面字段。备份包含原始 JSON 字符串，不修改损坏内容。
- 两个 HTML 入口字节同步，立绘、已有决策回执和游戏数值保持原有行为。

## 验收

- `bash tests/run-all.sh 400`：12组通过，0失败，0跳过；含400局数值校准。
- 新增`tests/12-android-startup.js`：15项兼容与存档保护检查通过。最终的弹窗背景隔离调整后，重新通过启动兼容和34项界面流程检查。
- Codex In-app Browser，本机 HTTP 服务：390px下在缺少可选接口的隔离环境中完成取名、路线选择、上任和跑业务回执；指标与行动均为6项，图标占位文字为0，无横向溢出。
- 320px下检查损坏存档恢复界面和原文备份，主脚本语法错误仍有独立恢复界面；存储被拒绝仍进入引导。隔离页面使用内存存储，不读取玩家存档。
- 截图保存在`tests/out/安卓启动-兼容模式.jpg`和`tests/out/安卓启动-存档恢复.jpg`。
