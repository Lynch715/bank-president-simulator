# 手机页面滚动、按钮与重开流程

## 修复内容

1. **图鉴被遮挡**：开屏与结局原来的层级分别为 80、60，图鉴所在弹窗为 50，导致按钮触发后内容出现在原页面后面。弹窗层级调整为 85，并同步隔离下层页面的交互；关闭后恢复当前页面。
2. **图鉴双层滚动**：移除图鉴列表自己的高度限制和滚动区，使用弹窗整体滚动。结局、成就、天赋、挑战四页均能滚到最下方的关闭按钮，背景不随之移动。
3. **排行立绘点击区域过窄**：原窄屏按钮宽 24～28px，统一为 44×56px。行长姓名可换行，320px 宽度下页面不横向溢出。
4. **每次重开重选任期**：中途确认重开与结局再开一局都回开屏；玩家重新选择三年、六年或十年，再取名、选路线。取消重开保持原进度。确认重开后清空旧局与事件队列，查看图鉴不会恢复旧存档。
5. **开屏后续入口**：首次结局后无需刷新，开屏立即显示图鉴入口；从开屏进入挑战会正确关闭开屏，挑战仍使用各自固定规则。
6. **兼容分支**：无 MutationObserver 时，结局、成就提示与账册切换也直接完成图标转换，避免残留 `[icon:...]`；关闭图鉴与进入结局直接同步背景锁定状态。

## 浏览器验收

通过 Codex In-app Browser 和本地 HTTP，使用内存存储场景，不读取或改写玩家存档。

- **320×568**：网点、团队、关系、经营、贷款、排行、日志七页，逐页检查顶部和底部。均无横向溢出；可见按钮无遮挡、触控区域不小于 44px；长列表底部可达。
- **390×700**：首页图鉴四页、六项行动、派主任/调回主任、装修、培训、解雇、长期项目、人物大图及返回、月末结算和后续事件。
- **结局**：打开图鉴、解锁天赋、返回图鉴和结局，返回后结局滚动位置保留；传记 Canvas 正常生成；再开一局回开屏。
- **重开完整流程**：从第七年中途重开，回开屏改选六年，完成取名、路线和天赋选择，上任后剩余 72 个月。
- **390×360 短屏**：取名、路线底部选项、天赋和上任按钮可达。
- **844×390 横屏**：设置可滚到底部，联系方式正常展示，无横向溢出。
- **兼容模式**：禁用 MutationObserver 的结局图鉴可通过原生点击打开、长列表滚到底部、关闭后回到结局；页面控制台无运行错误。
- **边界反馈**：满编招聘显示“编制满了”，可正常关闭。

## 自动化回归

- `tests/14-mobile-interactions.js` 覆盖标准/兼容两种环境，检查图鉴层级和返回、图标转换、重开取消/确认、重选年限、路线选择与挑战入口。
- `tests/05-ui.js` 增加中途重开先回开屏，以及首次结局后立即显示开屏图鉴的回归。
- 通过 `bash tests/run-all.sh 400` 检查所有 14 组回归，另核对两个 HTML 入口及独立/内嵌样式同步。

以上为浏览器尺寸模拟与自动化测试，未做实际手机触摸帧率、实体键盘或系统软键盘验收。线上版本需另确认 Pages 构建完成并比对实际文件哈希。
