# 纸墨经营界面改造

采用 paper-ink-management-ui 的台账层次、宋体标题、纸面卡片与移动导航。按用户要求更换主题：藏蓝 #253e52、暖纸白 #f2eee5、朱砂 #a44335，褐金只用于少量数字与提示。当前为固定浅纸色主题，没有新增自动或手动暗色切换。

样式源为 styles/paper-ledger.css，全部限定在 .pm-ui 内；同份 CSS 内嵌到 index.html 和模拟银行.html，保留单文件运行方式。修改样式后须同步内嵌块与两个入口。

桌面为左侧概览、右侧决策与账册；760px及以下改为单列和底部账册导航。去掉大幅图片首屏，开局使用纸面说明。事件、图鉴、结算、经营项目、提示、传记导出和应用图标统一配色。

行动改用原生按钮，显示精力消耗；项目不可建设时显示原因。保留玩法与经营数值。取消禁止缩放，补充键盘焦点、指标键盘说明、弹窗焦点约束与背景交互隔离。

## 本轮验收

- Codex In-app Browser，localhost：1280px桌面、390px手机、320px窄屏、760/761px断点均检查，无页面横向溢出。
- 开局说明、主界面、长网点名、空贷款列表、项目禁用原因、选中导航、事件弹窗、月报正负变化均已检查。
- 通过隔离测试页面把主要正文从12–14px放大到24–28px，390px下可换行阅读。此项是字体放大场景，不等同于手机系统字号或浏览器缩放真机测试。
- 事件弹窗内Tab从最后一个选项回到第一个，焦点未进入背景。保留prefers-reduced-motion样式，未执行系统级动画偏好切换。
- jsdom界面流程34项与传记生成6项通过。没有重新校准数值，因为本轮未修改经营算法。
- 未做真机验收；未发布线上。
