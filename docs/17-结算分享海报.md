# 结算分享海报

后续手机保存与分享兼容修复、原图保存页及最新验收记录见 [18-手机海报保存与分享兼容修复.md](18-手机海报保存与分享兼容修复.md)。

大结局出现后自动绘制本局海报，输出 1080×1440 PNG。包含结局、玩家姓名、经营路线、计划任期、实际在任月数、最终存款、全区排名、网点、团队及累计放贷；提前结束与正常完成分别标明。失败局与长姓名也能保存。

结局页展示真正的 IMG，可点击“保存海报图片”下载，或在手机浏览器中长按图片保存。支持文件分享的环境显示“系统分享”；取消分享不会自动下载，失败后仍可保存。下载文案说明发起下载以及浏览器下载目录/文件位置，不宣称已经写入相册。

海报底部保留“制作人 大老师 · 微信 lynchrrr”和小红书、闲鱼搜索原创作者“模拟游戏大全”的提示，真实二维码指向线上游戏。海报不写入存档、图鉴、阅历或随机数；重试不重复结算。重开时清理 Blob URL，并阻止尚未完成的上一局海报插入新局。

## 资源与构建

- 底图采用内置 image_gen 生成，翡翠金框、江城黄昏、米白信息区；原图与压缩 JPEG 保存在 `assets/settlement/`，完整提示词见该目录 `prompt.json`。
- 中文和成绩由 Canvas 绘制，二维码由 Core Image 编码生成，不使用生图生成文字或二维码。
- `python3 scripts/build-settlement-poster.py` 同步 `scripts/settlement-poster.js` 和两个内嵌图片数据到两个 HTML 入口；`python3 scripts/sync-styles.py` 同步样式。
- 海报渲染代码单独放置，主游戏执行脚本仍小于 300KB；JPEG/二维码作为位于主脚本之后的 JSON 数据，仅在结局时解码。无须外部图片请求，单文件离线仍可生成海报。
- Canvas 不可用时显示重试和可读说明，原结局数据、图鉴、传记与重开按钮保留；底图或二维码异常时仍可生成文字版海报。

## 验收

- `bash tests/run-all.sh 400`：16 组通过，0 失败、0 跳过；新增 `tests/16-settlement-poster.js` 34 项，覆盖真实 PNG、真实结局入口、2/3/6/10 年任期、提前结束、长姓名、状态/存储/随机数不变、分享取消与失败、重试及异步重开。
- 应用内浏览器实际点击“保存海报图片”，导出 1080×1440 PNG，约 2.2MB。原有玩家存档未用于结局测试，测试页使用隔离内存存储。
- Vision 解码验证独立二维码和实际下载海报，结果均为 `https://lynch715.github.io/bank-president-simulator/`。
- 应用内浏览器确认实际视口 390×844、320×568 与 844×390，预览有完整 1080×1440 像素、无横向溢出，窄屏保存与分享按钮高度 44px。320 宽且禁用 MutationObserver 时，提前结束海报、图鉴打开/关闭和重开均正常；横屏底部重开可达，点击回开屏。
- 以上为浏览器尺寸模拟，手机原生长按菜单、相册写入以及微信/小红书客户端分享未在实体手机上验收。文件分享成功/取消/失败分支使用能力模拟验证。
