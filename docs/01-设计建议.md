# 《模拟银行行长》迭代设计建议 v1.0

> 设计:Fable5 · 施工:Opus5 · 日期:2026-08-31
> 配套文档:《02-施工规范.md》(实现约束与验收标准)

## 一、现状盘点(基于 index.html v5, 2668行)

已有骨架相当扎实,同类单文件文字经营游戏里属上乘:

- **核心循环**:36个月 × 每月3点精力 → 月度结算 → 事件/主线/对手出招 → 季考/年考
- **4条路线**(对公/零售/关系/合规):各带数值修正、专属事件池、路线目标与专属结局
- **6个NPC**:好感 + 60/80特权 + 多幕主线弧(NPC_ARCS)
- **8个对手支行**:差异化增长率 + 4种主动出招(抢人/挖客户/举报/挖关系)
- **员工**:三维属性 + 8特质 + 倦怠跑路;**贷款**:12客户池 × 3风险档 + 不良转化
- **文案**:重庆在地感强,白描短句,是本作最大差异化资产

**主要短板**(对标同类后的诊断):

| # | 问题 | 表现 |
|---|------|------|
| S1 | 一周目即终点 | 通关后无收集、无继承、无再开动机 |
| S2 | 结算即终结 | 结局只有一段文字,没有可截图分享的"这一局的故事" |
| S3 | 经济模型太平 | 收入=存款×2万/亿,存款是唯一硬通货,利润/成本无博弈 |
| S4 | 中期疲态 | 第13~28月循环重复,无宏观节拍变化,弹窗节奏单调 |
| S5 | 灰色选择无账 | 灰色操作只涨"风险"数值,不留案底、不进结局 |
| S6 | 对手是背景板 | 排名只在季考出现,对手自身无兴衰剧情 |

## 三、改进方案(按优先级)

### P0-1 结局图鉴 + 成就墙 【重玩性】
- 新增"图鉴"入口(标题页+结局页)。结局矩阵:4路线专属 + 4排名结局 + 失败结局 + 新增隐藏结局,已达成点亮,未达成显示剪影+一句暗示。
- 成就 16~24 个,存 localStorage(独立于存档)。示例:`零不良通关`、`三年不喝一顿酒`、`第7名逆袭第1`、`把陆嘉禾培养到三星`、`收下所有把柄还全身而退`。
- 成就达成时 toast 弹一条,不打断流程。

### P0-2 行长传记(结算长图) 【传播】
- 终局后生成一张 canvas 长图:标题称号 + 36月大事时间轴(取 log 中标记为关键的 8~12 条)+ 五维雷达(存款/口碑/士气/干净度/人脉)+ 路线徽章 + 一句毒舌总评 + 现有推广二维码。
- "保存图片"按钮(canvas.toBlob 下载)。这是本作的自传播抓手,优先级最高。
- 关键事件打点:在 log() 增加 `key:true` 标记位,施工时对约30处大事补标。

### P0-3 开局天赋(周目继承) 【重玩性】
- 通关(无论结局)按表现折算"阅历点"。二周目起,开局三选一天赋,消耗阅历点解锁池子。
- 天赋示例(每条对应一种玩法倾斜,勿做纯数值+):`老领导关照`(陆初始好感+15)、`背水一战`(开局现金-100万,全年产出×1.1)、`旧部来投`(开局多一名4星随机员工)、`识人之明`(招聘刷新免费)。
- 天赋池 10~12 个,首周目不显示入口,避免干扰新手。

### P0-4 结算降噪 + 趋势图 【UX】
- 平静月(无主线/连锁/对手/事件)把月报和"下一步"合并为一屏,少点一次。
- 月报顶部加 12 个月存款迷你折线 + 当前排名箭头(↑↓),canvas 60×24 即可。
- 弹窗队列上限:单月最多 3 个剧情弹窗,超出的顺延下月(军令状/年考除外)。

### P1-1 宏观信贷周期 【经营深度】
- 36 个月脚本化三段:宽松(1-10月)→ 收紧(11-22月)→ 再宽松(23-36月),每局在节点上±2月抖动。
- 宽松期:贷款需求多、派生×1.1;收紧期:不良基准×1.5、存款自然流失、检查类事件权重×2。
- **关键:提前2个月用"新闻"预告**(月报里一条行业消息),让玩家能布局——这是策略感的来源,没有预告就只是随机惩罚。

### P1-2 净息差 lite 【经营深度】
- 收入公式改为:`贷款利息收入 + 存款×基准收益 − 存款×付息成本`。
- 新增行动"高息揽储"(1精力):当月存款+快,付息成本上浮 6 个月,口碑-2。让"冲存款"第一次有了代价。
- **红线:改完后三年难度带必须与现版一致**(校准方法见施工规范),否则老玩家体感崩坏。

### P1-3 把柄系统(灰度暗线) 【剧情】
- 隐藏计数器 `dirt`(不直接显示,UI 只在 ≥3 时于风险栏出现一个模糊图标 🗂)。灰色选项(现有事件中约15处)各 +1~+2。
- 年度审计/巡视事件时掷骰结算:dirt 越高越可能爆,爆了走"双规/免职"新失败结局;顾清越好感≥80 可挡一次(消耗)。
- 结局矩阵加"干净度"维度:同样第一名,dirt=0 出`干净的第一名`隐藏结局,dirt 高出`带病提拔`结局(埋二周目彩蛋文案)。

### P1-4 站队主线 【剧情】
- 第 20~24 月触发强制事件"分行的风向":陆明远(业绩派)与顾清越(合规派)矛盾公开化,玩家三选:站陆/站顾/骑墙。
- 站队后:对应者好感+15、另一方-20,各解锁 2 个专属事件;骑墙:双方各-8,但保留"谁赢帮谁"的终局变数。
- 复用现有 `flags.followLu` 逻辑,扩展为 `flags.faction`。

### P1-5 黑天鹅年度大事件 【剧情/节奏】
- 每年 1 个多幕大事件(3幕,跨2~3个月),从池中抽取不重复:`房企暴雷`(对公贷款连环)、`挤兑谣言`(短视频发酵,口碑/存款保卫战)、`柜员卷款`(内控危机)。
- 结构:预兆幕(小损失+线索)→ 抉择幕(2~3 种应对路线)→ 结算幕(按前两幕选择差异化)。复用现有 chain 机制,不需要新框架。

### P2-1 对手兴衰 【世界感】
- 每局随机 1~2 个对手有自己的"剧本":南岸黄世海(灰色)可能在第二年被查(存款腰斩,事件里玩家可趁机接收客户或拉一把结善缘);渝北马奔冲太猛可能爆不良。
- 同业微信群消息流:季考弹窗里加 2~3 条对手动态短讯,成本极低,世界感回报高。

### P2-2 挑战模式 【重玩性】
- 通关后解锁:`修罗开局`(存款5亿第8名起步)、`廉政风暴`(全程检查×2,灰色选项禁用)、`速通`(24个月版)。
- 种子挑战:输入种子字符串复现同一局(需要把 Math.random 换成可注种子的 PRNG——工程量在施工规范中单列,若超预算可砍)。

### P0.5 摊派事件补丁 【真实感/日常】 ✅已施工(2026-09-02, Fable5)
背景:玩家提议6个日常随机事件(反诈/保险/投诉/请假/ETC/内审)。评审结论:投诉撞现有`complaint`、内审撞`inspect`/`auditdrill`(内审价值已由P1把柄年审承接)、反诈撞`fraud`;真正落地3项,共用"上级摊派"张力结构:

- **`insurance`升级**:原2选项基础上,新增社牛特质专属选项"指标交给他去冲"(现金+15万、该员工倦怠+12、士气-2)——摊派型事件的核心张力:完成指标的代价摊在谁头上。
- **`etctask` ETC大会战**(新增):全员下路口(现金+10万、陆好感+4、全员倦怠+8、士气-4)/ 报虚数(风险+4、dirt+1)/ 如实报做不完(陆好感-4、士气+3)/ 愣头青专属:一人包活(完成、倦怠+18、营销+1)。银行人集体记忆名场面,自带传播梗。
- **`leave` 一张请假条**(新增,带pre随机员工+随机事由):批一个月(倦怠-40、士气+5、存款-0.08亿)/ 批三天(倦怠-10、士气+1)/ 不批(士气-6、倦怠+15,高倦怠由现有跑路机制承接)。

验收:simBatch(200) 与基线对比,难度带无漂移(中位存款27.5亿,结局分布一致),零报错。

### 不做清单(明确排除)
- 不做实时/放置玩法,不做多存档槽以外的云存档,不做数值通胀式加系统(新增资源仅 dirt 一项),不拆文件不引框架。
