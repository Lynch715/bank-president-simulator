# 美术 / 按钮 / 溢出 审计

> 审计:Opus5 · 日期:2026-08-31 · 版本:index.html 4057 → 4107 行(含第六节补的工具行)

## 一、怎么审的

不是靠读代码猜,是**在真 Chrome 里量的**。

沙箱里装不上 Chromium(下载源被网络策略挡了),浏览器扩展又打不开 `file://`。所以做法是:把 `index.html` 的 `<style>` 整块抽出来(两张内嵌大图换成纯色渐变,不影响布局),配上覆盖全部 UI 面的**手写最坏情况标记**,在你本机 Chrome 里用 `<iframe>` 渲染——用 iframe 是因为 CSS 媒体查询认的是 iframe 自己的视口宽度,这样 640px 断点会真的触发,而不是靠模拟。

然后跑一段量化脚本,对页面里每一个元素检查四件事:

1. **冲出视口** — `rect.right > 视口宽` 或 `rect.left < 0`
2. **文字被容器切掉** — `scrollWidth > clientWidth` 且 `overflow-x` 是 hidden/clip
3. **溢出父容器内容区** — 元素边界超过父元素的 padding box
4. **触控目标过小** — 按钮实测高度 < 40px

外加一遍 **WCAG 对比度计算**:逐元素求有效前景色(算上 `opacity` 的层层累乘和 rgba alpha)与有效背景色的亮度比,正文要求 4.5,大字要求 3.0。

测了 6 个宽度(视口 305 / 345 / 360 / 399 / 625 / 753 / 1265),每个宽度跑两轮:一轮常规内容,一轮**极限文案压力测试**——文案是从 `index.html` 里正则抽出来的实际最长字符串:60 字的路线结局文案、148 字的贷款选项副标题、11 字的成就名、5 个网点名串在一起的预警、17 枚徽章、4 位数负现金。

## 二、溢出:一处都没有

**这是最值得说的结论。** 六个宽度 × 两轮内容,`出画布` / `文字被切` / `溢出父容器` / `页面横向滚动` 全部为 0,包括 305px 这种比 iPhone SE 还窄的视口。

原因也清楚:布局通篇用 grid/flex + `flex-wrap`,固定宽度只出现在三处(`.stat .tip` 190px、`.trendbar canvas` 200px、`.gal .gi` 26px),而这三处都有对应的移动端覆盖规则。`white-space:nowrap` 只用在四个内容长度固定的地方(精力点、结束本月、标签页、迷你折线)。**这一条不用改。**

## 三、对比度:三处不达标,已修

用 WCAG 公式实测出来的:

| 元素 | 原对比度 | 要求 | 问题 |
|------|---------|------|------|
| 禁用选项的 `<small>` | **1.82** | 4.5 | 廉政风暴的「此路不通」说明。这行字正是玩家需要读懂"为什么这条路被封"的唯一线索,却几乎看不见 |
| 禁用选项的主标题 | 2.59 | 4.5 | 同上,连选项本身写的什么都难认 |
| 图鉴未解锁条目的暗示句 | **2.55** | 4.5 | 未解锁结局的那句暗示,是整个图鉴勾人的地方,却比背景亮不了多少 |
| 图鉴未解锁条目的标题 | 4.18 | 4.5 | 差一点 |

根因是两个 `opacity`:`button:disabled{opacity:.35}` 和 `.gal{opacity:.55}`。**opacity 是乘在整棵子树上的**,本来就偏灰的 `--dim` 再乘 0.35,就掉到了背景色附近。

改法:禁用态 `.35 → .62` 并给禁用选项单独一个略深的底色和更亮的 `small` 颜色;图鉴未解锁 `.55 → .78`,暗示句单独提亮到 `#a3abb8`。**改完复测,不达标列表为空。**

## 四、按钮:触控目标偏小,已修

实测手机宽度下低于 40px 的按钮:

| 按钮 | 原高度 | 归属 |
|------|-------|------|
| 六个标签页(网点/团队/关系/贷款/排行/日志) | **34px** | 原版。全局点得最多的控件 |
| 卡片里的操作按钮(换主任/培训/解雇…) | 35px | 原版 |
| 「结束本月」 | 38px | 原版 |
| 「再开一局」 | 38px | 原版 |
| 图鉴里的「解锁 / 开始」 | **34px** | 我在 P0/P2 加的,**违反了施工规范 §6 自己定的 40px 下限** |

改法分两块:

- 图鉴按钮 `min-height` 直接提到 40(这条是我自己欠的)。
- 其余的**不动桌面版式**,只在触屏上补:新增 `@media (pointer:coarse)` 规则块统一给到 40/44。用 `pointer:coarse` 而不是宽度断点,是因为 768px 的平板竖屏也是手指点,但它宽度超过 640,原来的移动端规则够不着它——实测确实漏了(768px 下卡片按钮仍是 31px)。

复测:手机宽度下只剩「关上」正好卡在 40px(达标),其余全部 ≥40。

## 五、顺带查出来的四件事

**1. 军令状信息重复显示。** 同一条军令状同时出现在警告条和预报条里,一句话说两遍,还占掉窄屏一行。已删掉预报条那份——警告条那条信息更全(带当前存款)。

**2. 警告条没有上限。** 最坏情况(风险爆表 + 欠薪 + 不良 + 倦怠 + 缺主任 + 军令状 + 连锁事件)能同时挂出 7 条,在 375px 屏幕上占满整整一屏,把真正要操作的行动区推到折叠线以下。**预警占满一屏,反而没人看。** 已改成按红→黄→蓝排序、最多显示 4 条,超出的折叠成一行「…还有N条」。

**3. `warnings()` 里的现金流公式是 P1 之前的老版本。** 它还在用 `S.dep*2` 算收入,既没走 `BALANCE.nim.baseYield`,也没扣「高息揽储」的付息成本——也就是说玩家用过高息揽储之后,「每月净流出 X 万」这条预警报的数是偏乐观的假数。这是我在 P1-2 改净息差时漏掉的一处调用点。已修。

**4. info 类预警的图标是文本字形。** 🚨 和 ⚠ 都是彩色 emoji,只有 `ℹ` 是单色文本字形,在一排预警里明显"掉色"。缺主任那条改成了 🪑(空着的椅子),跟语义也更贴。

## 六、补上一个真缺口:游戏中没有重开和图鉴的入口

审计过程中你指出来的:**开局之后,界面上根本没有「新开一局」。** 查证属实,而且比这更糟——图鉴也没有。

这两个入口原来只挂在两个地方:开局前的玩法说明页、走完一局后的结局页。也就是说,一个存档在手的玩家,想中途换条路线重来,只能去清浏览器的 localStorage;想翻翻还有哪些结局没点亮,得先把这一局打完。

已在顶栏下面加了一条工具行(右对齐,两个低视觉重量的小按钮):

- **📖 图鉴** — 随时可开,四页照旧。关掉回到原状态,不影响进度。
- **🔄 重开一局** — 先弹确认,把当前进度(第几年几月、存款、排名)报给你,并写明两件事:**存档会没**,以及**没走完的任期不折算阅历点**(阅历只在走完一局时结算,中途弃局不给)。图鉴和成就是另存的,不受影响。

实测(375px 真机):按钮 40×70 和 40×89,贴右 8px 边距,文字对比度 6.49,无溢出。图标本来用的是 `↻`,是单色文本字形,跟旁边的 📖 不是一个体系,换成了 🔄。

UI 测试补了 8 项覆盖这条路径:两个入口存在、图鉴开得开关得掉且状态不丢、重开要确认、确认框里报了当前进度、选「算了」这一局原封不动、真重开之后回到第1年1月存款10亿。

## 七、看着还行、但留给你定的三点

这些是观感判断,不是缺陷,我没动:

1. **路线徽章的 emoji 是彩色的,混在灰色文字行里有点跳**(比如结局页那行「行长 欧阳博雅 · 🛡合规稳健」)。这是原版就有的风格选择,统一改成单色符号会更克制,但也会丢掉辨识度。
2. **`.dirtic` 上挂了 `filter:blur(.3px)`**,是我在 P1 故意做的"看不太清"的效果。在高分屏上可能被当成渲染瑕疵。要不要保留看你。
3. **卡片按钮在窄屏会折成两行**(网点卡片有 4 个操作),视觉上有点碎。可以考虑把低频操作(关停整改)收进二级菜单,但那是交互改版,不在这轮审计范围。
