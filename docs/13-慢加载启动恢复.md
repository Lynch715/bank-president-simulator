# 慢加载启动恢复

## 新证据

用户后续截图显示版本 android-startup-20261015，错误为“启动流程未完成”，浏览器上报 Android 16、Chrome 144。该提示来自15秒看门狗；截图没有记录主脚本到达时间，不能据此确认原手机网络或实际内核行为。

已复现第一轮修复中的确定缺陷：主脚本晚于15秒到达后，超时逻辑已把 broken 永久置为 true。随后即使主脚本执行成功，也不会打开引导或清除错误页。使用本机真实 HTTP 分段响应延迟18秒，旧版确实停在错误页，新版自动恢复。

## 修改

- 15秒仅显示可恢复的等待提示，后续主脚本到达自动继续；捕获到的实际异常、损坏进度仍保持阻断与备份入口。
- 可执行主脚本从约1.09MB降至265,661字节。23张内嵌立绘的约824KB编码移到脚本之后的 application/json 数据段，游戏可先运行；数据到达后补图，期间使用已有独立 WebP。HTML总传输体积基本不变，完整单文件仍包含全部人物图。
- 诊断增加初始化阶段、文档状态、主脚本字符数和等待时间，版本为 android-stream-20261015。
- 更新图像构建脚本与测试脚本提取逻辑，两个入口保持字节一致。
