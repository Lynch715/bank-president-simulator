# 首页滚动与制作人信息

## 原因与修改

- 原先 document 始终注册非 passive 的 touchmove。即使单指只走判断、不调用 preventDefault，浏览器仍可能等待主线程处理该监听。现在只在第二根手指落下后临时注册阻塞监听，回到单指或取消手势即移除；保留双指及 iOS gesture 缩放拦截。
- 首页、弹窗缺少滚动边界隔离。应用内浏览器 390×700 复现：首页到达 scrollTop≈173 后继续下滑，背景 scrollTop 从 0 变成约 89.5。现在浮层显示时锁定根页面滚动，为浮层设置 overscroll-behavior-y:contain；关闭后解除锁定。
- 首页及设置页底部加入 11px 小字：制作人 lynchrrr · 微信：lynchrrr；发现更多游戏，请在小红书、闲鱼搜索原创作者“模拟游戏大全”。设置正文原来的联系方式移到底部。
- 同步 index.html、模拟银行.html，以及 styles/paper-ledger.css 与内嵌主题。
